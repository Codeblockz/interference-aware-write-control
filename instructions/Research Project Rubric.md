# EN.705.742 — Research Project Rubric

Five criteria, 100 points total. Levels are 26 / 16 / 8 / 0 (the first two criteria) and
16 / … for the rest as scaled in Canvas.

## INTRO — Introduction and Goals

**Full credit:** topic and project goals clearly defined; rough research and/or development
approach described; hypotheses stated. What ML problem is solved? What method of analysis?

- *Partial:* problem and solution clear but reasoning is not; steps described too roughly.
- *Low:* jumps into code and analysis without preparing the reader.
- *Zero:* the ML topic, method, or input data is irrelevant.

## HYPOTHESES & METHOD — ML Problem and Method Description

**Full credit:** algorithm/method description, the math behind it, and code are sound;
demonstrates you know your applied ML method. **A block diagram is expected.**

- *Partial:* sound description unsupported by prototype runs or research; no block diagram.
- *Low:* improper data, insufficient performance criteria, code that errors or doesn't run.
- *Zero:* approach irrelevant to applied ML objectives.

## RESEARCH — Related Work

**Full credit:** correct or convincingly novel approach; theoretical research complete.
- *Partial:* mediocre related work, existing methods under-explained.
- *Zero:* no related work.

## APPLICATION — Method and Solution

**Full credit:** sound solution **with metrics**; correct execution of the ML method;
proper runs and statistics collected; explicit link between problem and solution.
- *Partial:* unconvincing empirical runs, no evaluation, no hyperparameter search where
  applicable, no link between theoretical and empirical analysis.

## WHAT IS LEARNED? — Conclusions

**Full credit:** conclusions supported by the method sections; answers *why* the work was done.
- *Partial:* conclusions only restate the obvious.
- *Zero:* no conclusions; references improper.

## The two things most likely to cost you points

1. **No block diagram** — called out explicitly in two separate criteria.
2. **Metrics and statistics** — "sound solution *with metrics*, proper runs and statistics
   collections." A working model with no evaluation lands in the partial column.
