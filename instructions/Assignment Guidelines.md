# EN.705.742 — Assignment Guidelines

Transcribed from Canvas → Course Information → *Assignment Guidelines*.

## Shape of the work

Every module has a problem set, completed **individually**. A few questions want direct
answers; most want a machine-learning pipeline in a Jupyter notebook using pandas, numpy,
scikit-learn, PyTorch and similar. Each set ends with one or two conclusion/evaluation
questions about the problem and your pipeline's performance.

**100 points per problem set**, partial credit available. Due **Day 7** of the module.
**No late problem sets without prior approval.**

## Quizzes

Quizzes exist to make you watch the module videos. Some questions will look irrelevant —
they are there to measure attention to the material. Watching the videos should be enough
for full marks.

## Submission — the rules that actually cost points

1. Notebook contains **code and results** (plots, tables) that justify your answers.
2. Written answers go in **Markdown cells**. *Not* in code comments, not in the Code
   section. Comments are for you, not the grader.
3. Submit as `.ipynb` in original format to the module's Assignment link.
4. Name it **`Ellis-AssignX.ipynb`** where X is the module number (1, 2, … 14).
5. **Before submitting: Kernel → Restart & Run All.** Then save and submit *that* copy.
   If the notebook was not run from a clean restart, the grader or instructor **may reject
   the submission**.

## Grading

100 points per assignment, split across problems by length and difficulty, indicated at
the start of each question. Graded for **relevancy, accuracy, and completeness**. The
notebook is expected to run start to finish on a clean kernel. Markdown cells carry the
answers, the explanation of your approach, and your commentary.
